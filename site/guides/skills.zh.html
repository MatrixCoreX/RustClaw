安装和使用 $brand 的 Agent 技能

技能让 Agent 能处理文件、转写语音、采集和下载媒体，也能查询天气预报。启用技能后，在对话里说清楚输入是什么、希望拿到什么结果，Agent 就能按任务选择可用技能。

查看、安装和启用技能

  1. 在网页控制台首页打开工具技能，查看已经安装的技能和它们的启用状态。
  2. 需要新技能时，打开 Skill Store。先核对支持的平台和依赖项，再按需安装。
  3. 确认技能已启用，回到 Agent 聊天。比如上传一份 PDF，问「读一下这份文档，列出待跟进事项和截止日期」。

媒体采集技能

启用媒体采集后，可以指定支持的平台、关键词和本批数量。采集结果可以保留预览、作者文案、来源链接和采集当时能读取到的互动数据。

「在小红书和抖音各采集一条关于露营装备的帖子，保留作者文案、预览和来源链接。」

打开 AiAPP → 媒体发现，可以按平台或内容类型筛选、预览结果和打开原帖。需要持续采集时，可以在 Agent 中提出开启、暂停或停止的请求。

查看媒体采集支持的平台和执行方式

媒体下载技能

启用媒体下载后，把支持平台的作品链接或完整分享文案发给 Agent。可以保存能获取到的原视频、原图，以及支持的图文作品正文。图片较多时会打包为 ZIP。

「保存这条露营图文的原图和正文：[粘贴小红书分享链接]。」

可以从 Agent 回复里下载文件，也可以到 AiAPP → 媒体下载查找已保留的任务和附件。记录覆盖 Agent 聊天和已接入的消息渠道。

查看媒体下载支持的平台和交付格式

天气查询技能

在 Skill Store 找到 weather 技能，安装并启用后，回到 Agent 聊天发送这条请求。

「帮我查杭州未来三天的天气，按天列出天气状况、最低和最高气温。」

技能从 Open-Meteo 获取天气数据，无需天气 API Key。只想查当前天气时，说出城市即可。想看逐日预报时，再告诉 Agent 要查几天。

查看天气技能支持的查询方式

语音转写技能

在控制台打开大模型 → 多模态模块 → 语音转写，确认转写已启用并配置好识别模型。然后回到 Agent 聊天，上传 meeting.wav 并发出这条请求。

「把我上传的会议录音 meeting.wav 转成文字，回复里贴上全文，再给我一个 TXT 文件。」

任务完成后，可以在回复中阅读完整文字稿。点击 transcript.txt 旁的下载按钮即可保存一份。

AiAPP 如何展示技能结果

管理员可在 AiAPP 打开配套视图，或从安装应用为已启用的技能添加视图。媒体任务结束后，可以回这里筛选记录、查看来源或下载文件。

由技能包声明
技能在 skill.toml 的 [aipp] 段声明可选配套界面。应用访问取决于已安装的技能版本、启用状态和宿主授权。
控制台按版本化约定提供数据
媒体发现读取技能自己的采集记录。媒体下载展示保留下来的技能任务和结果附件。
自定义界面在沙箱运行
技能包可以随附静态界面。应用通过宿主的能力白名单发出请求，由宿主校验授权。
