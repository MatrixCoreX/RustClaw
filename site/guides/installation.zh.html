请查看对应版本的发布说明，确认系统要求。安装脚本需要 Bash、Python 3.11 或更新版本、curl、tar 以及 OpenSSH 的 ssh-keygen。磁盘需要留出下载、解压和安装的空间。

uname -s
uname -m
python3 --version
df -h "$$HOME"

在 Ubuntu 上安装

在 Ubuntu 电脑或服务器上执行上面的检查。如果架构显示 x86_64，请确认脚本选中的发布标签以 ubuntu-x86_64- 开头。安装脚本会配置 systemd 自启动。

校验并运行安装脚本

在 macOS 上安装

在 Mac 上打开「终端」。Apple 芯片 Mac 的原生终端显示 arm64，使用 macos-aarch64- 发布包。Intel 芯片 Mac 显示 x86_64，使用 macos-x86_64- 发布包。安装脚本会为当前账号注册 LaunchAgent。

校验并运行安装脚本

校验并安装签名发布包

从项目的 GitHub 仓库下载安装脚本，再用 --check-only 查看脚本选中的发布包。

curl -fL -o install-latest-release.sh \
  https://raw.githubusercontent.com/$release_repository/main/install-latest-release.sh
bash install-latest-release.sh --repo $release_repository --check-only

把选中的发布标签与上表对照。匹配后运行安装脚本，它会检查发布签名和校验和，默认安装到 ~/agent-runtime 并启动服务。

bash install-latest-release.sh --repo $release_repository
"$$HOME/.local/bin/agentctl" -status
"$$HOME/.local/bin/agentctl" -health

查看 GitHub 发布列表 完整的安装、签名校验和更新说明

打开网页控制台并发送第一个任务

  1. 在运行 $brand 的设备上打开 http://127.0.0.1:8788。如果服务装在远程服务器上，可从自己的电脑通过 SSH 转发端口。
  2. 在安装目录的 data/bootstrap-credentials.txt 中查看初始登录信息，登录后修改初始密码。
  3. 打开「大模型」，保存并测试一个文本模型，然后在「Agent」里发送一条简短指令。收到回复后，可以确认控制台、后台服务和模型能正常通信。
