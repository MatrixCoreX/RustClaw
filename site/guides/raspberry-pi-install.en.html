Check Raspberry Pi OS, Python, and disk space

Run these commands in a terminal on the Pi, either locally or in an SSH session.

uname -m
getconf LONG_BIT
python3 --version
df -h "$$HOME"
  • The first two commands should return aarch64 and 64. If your system is 32-bit, use Raspberry Pi Imager to write Raspberry Pi OS (64-bit) to another card for a compatible Pi.
  • The installer needs Python 3.11 or later, Bash, curl, tar, and OpenSSH’s ssh-keygen. If curl or ssh-keygen is missing on Raspberry Pi OS, run sudo apt update and sudo apt install ca-certificates curl openssh-client.
  • Check the free space on the last line. Leave room for the downloaded package, its extracted files, and the installed copy.

Install the signed Pi ARM64 release

Download the project’s installer. Run it with --check-only to see the selected release before installing.

curl -fL -o install-latest-release.sh \
  https://raw.githubusercontent.com/$release_repository/main/install-latest-release.sh
bash install-latest-release.sh --repo $release_repository --check-only

Once the release tag starts with pi-aarch64-, run the installer.

bash install-latest-release.sh --repo $release_repository

The installer checks the package signature and checksums. It installs to ~/agent-runtime by default and starts the services. Verify them with these checks.

"$$HOME/.local/bin/agentctl" -status
"$$HOME/.local/bin/agentctl" -health

Open the web console and send a first message

On the Raspberry Pi, open http://127.0.0.1:8788 in your browser. To connect from another computer with SSH access to the Pi, run this command on that computer. Replace the user and address with your own, then open http://127.0.0.1:18888 there.

ssh -N -L 18888:127.0.0.1:8788 YOUR_PI_USER@YOUR_PI_IP
  1. After the first startup, find the initial sign-in details in data/bootstrap-credentials.txt inside the install directory. Change the initial password in account management.
  2. Open Models and save a usable text model. If it requires an API key, enter it in the console and test the connection.
  3. Open Agent and ask “What can you help me do in one sentence?” A reply confirms that the console, background service, and model can communicate.

Troubleshoot the release, console, or first task

The installer finds no matching release
Check the operating system bitness and architecture, then look for a pi-aarch64- tag in GitHub Releases. The small-screen component is packaged separately from the full Pi ARM64 service.
The web console won’t open
Run the status and health commands above. If you are using another computer, check that the SSH forwarding session is still open.
The console opens and the message remains queued
Verify the model in Models, then use Tasks to see whether the request is queued, running, or failed.
