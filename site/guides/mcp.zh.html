在 $brand 配置 MCP 服务器并测试订单查询

MCP（模型上下文协议）让 Agent 调用其他系统提供的工具。可以接入本机 stdio 命令或远程 Streamable HTTP 服务。第一次使用，可以下载下面的订单演示服务，试着按订单号查物流，再用快递单号反查订单。

添加服务器 下载并填写示例 设置工具权限 测试连接和查询 排查问题

添加本机或远程 MCP 服务器

用管理员账号登录控制台，打开大模型 → 外部工具服务器 → 添加服务器。可以添加多台服务器。每台服务器使用独立名称，分别设置连接方式、启用状态和允许的工具。

本机命令（stdio）
分别填写启动命令和命令参数，每行一个参数。命令由运行 Agent 的设备启动，程序和路径都要在那台设备上可访问。
远程服务（Streamable HTTP）
在连接方式中选择 HTTP，填写服务方提供的完整 MCP 地址，例如 https://tools.example.com/mcp。认证方式按服务方要求选择，支持 Bearer Token 或 OAuth 客户端凭据。表单填写环境变量名，例如 ORDER_MCP_TOKEN，变量值配置在 Agent 服务的运行环境中。

信任服务器并启用允许的工具

  1. 核对命令或地址，确认服务器由你管理或来自可信来源后，勾选我信任此服务器。
  2. 在允许的工具里每行填一个准确的工具名称。填写上面的两个查询工具即可完成订单演示。
  3. 打开启用此服务器和启用 MCP 工具，点击保存 MCP 设置。重启 Agent 服务，然后点刷新状态。

检查连接、工具列表和订单结果

  1. 看到服务器状态变为可用后，点击测试协议，确认显示连接正常。
  2. 检查工具数量和下方的名称。这个示例应显示两个已开放的订单查询工具。
  3. 回到 Agent 对话，用自然语言查询已知订单。Agent 可以从已开放的工具中选择。若界面要求确认，核对工具和查询参数后按提示操作。

单号应对应订单 3。示例里的物流位置和送达日期都是固定的模拟数据。

连接不上或 Agent 没查到订单时

找不到「外部工具服务器」
用管理员账号登录，在「大模型」页面向下找到 MCP 配置区。
「测试协议」按钮是灰色的
显示「等待保存」时先保存，显示「等待重启」时重启服务，再刷新状态。服务器达到「可用」后可以测试。
服务器可用，工具数量为 0
白名单留空时，开放的工具为 0。按服务方提供的准确名称逐行填写允许的工具，保存后重启并刷新状态。
连接正常，Agent 没查到订单
先确认工具列表里有对应的查询工具。使用示例订单 3 或单号 7898047967 复测，核对回复里的订单号和单号。
服务器显示「需要处理」
本机连接先检查服务进程能否找到启动命令并读取脚本。远程连接先检查服务主机能否访问 MCP 地址，以及运行环境是否已设置需要的凭据变量。
