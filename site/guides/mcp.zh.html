在 $brand 配置和测试 MCP 工具

MCP（模型上下文协议）让 Agent 调用其他系统提供的工具。接入订单查询后，可以让 Agent 从订单系统读取当前物流状态、快递公司和单号。

添加服务器 设置工具权限 测试订单查询 排查连接

添加本机或远程 MCP 服务器

在管理控制台打开大模型 → 外部工具服务器 → 添加服务器。每个服务器取一个独立的名称，并按服务方提供的信息填写连接方式。

本机命令（stdio）
填写启动命令和参数，每行一个参数。命令在运行 Agent 的设备上启动，路径也要填写那台设备实际能访问的位置。
远程服务（Streamable HTTP）
填写完整 MCP 地址，例如 https://tools.example.com/mcp。服务需要认证时，选择对应的认证方式。凭据字段填写环境变量名，实际值设置在运行服务的主机环境里。

选择允许 Agent 调用的工具

  1. 核对服务器的地址或命令，确认自己管理或信任它后，勾选我信任此服务器。
  2. 在允许的工具中逐行填写服务端提供的准确工具名。用订单示例起步时，可以先填写服务提供的只读查询工具。
  3. 启用这个服务器和启用 MCP 工具总开关，点击保存 MCP 设置。如果提示需要重启，按提示重启服务。

查看工具请求与权限的检查方式

测试连接，再查一笔订单

服务器状态显示可用后，点击测试协议。确认工具列表有订单查询工具，再回到 Agent 聊天发送请求。

「订单 3 到哪儿了？请告诉我快递单号。」

把示例订单号换成测试系统里已有的订单。收到回复后，对照订单系统里的物流状态和单号。

连接或工具不可用时检查什么

服务器显示「等待重启」
重启 Agent 服务，然后在外部工具服务器页面刷新状态。
服务器显示「可用」，工具数量为 0
核对允许的工具里的名称是否和服务端提供的完全一致，确认每行一个名称。
测试协议失败
先检查 Agent 所在设备能否启动本机命令或访问远程地址。服务需要认证时，再检查运行环境能否读取对应的凭据环境变量。
