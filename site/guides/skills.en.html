Install and use $brand agent skills

Skills give the agent ways to work with files, transcribe audio, collect or download media, and check weather forecasts. Once a skill is enabled, describe the result you want in Agent chat. The agent can select an available skill that matches the request.

Find, install, and enable a skill

  1. On the web console dashboard, open Tools & Skills to see installed skills and their enabled status.
  2. For an optional skill, open Skill Store. Check that it supports your platform and review the listed dependencies before installing it.
  3. Confirm that the skill is enabled. In Agent, describe the input and the output you want. For a document skill, attach a PDF and ask for a short list of action items and deadlines.

Media Discovery skill

With Media Discovery enabled, name the platforms, a topic, and a limit for your first batch. The results can include previews, author captions, source links, and engagement counts available at collection time.

“Collect one post about camping gear from Xiaohongshu and one from Douyin. Keep the captions, previews, and source links.”

Open AiAPP → Media Discovery to filter by platform or content type, preview a post, or open the source. You can also ask the agent to start, pause, or stop an ongoing collection.

Media Download skill

With Media Download enabled, paste a supported post URL or the full message copied from the platform's share menu. The skill can save available original videos or images, along with the original text for supported article posts. Larger image sets are delivered as a ZIP.

“Save the original photos and article from this camping post: [paste the Xiaohongshu share link].”

Download the files from the Agent result, or go to AiAPP → Media Download to review retained tasks and their files. The history includes tasks run in Agent chat and through connected messaging channels.

Weather forecast skill

Find the weather skill in Skill Store, install and enable it, then send this request in Agent chat.

“What’s the weather in Hangzhou for the next three days? List the conditions, low, and high for each day.”

The skill uses Open-Meteo and needs no weather API key. Give the agent a city for current conditions or add the number of days for a daily forecast.

See the weather skill’s query options

Speech transcription skill

In the console, open Models → Multimodal Modules → Audio STT and confirm that transcription is enabled and a speech recognition model is configured. Then attach meeting.wav in Agent chat and send this request.

“Transcribe the meeting recording I uploaded, meeting.wav. Paste the full transcript here and attach a TXT file.”

When the task finishes, read the full transcript in the reply and use the download button on transcript.txt to save a copy.

How AiAPP companion views work

Admins can open a companion view from AiAPP, or select Install app to add a view for an enabled skill. The media views make it easier to find a post or file after the conversation ends.

Declared by the skill
A skill can provide an optional [aipp] declaration in skill.toml. Access follows the installed skill version, enabled state, and granted permissions.
Data provided by the console
Built-in views use a versioned data contract. Media Discovery reads the skill's collection records. Media Download reads retained task results for that skill.
Custom views run in isolation
A skill package can include its own static interface. It runs in a sandbox and requests capabilities through the host's allowlist.

When a skill is missing or the task gets stuck

The skill is missing from Tools & Skills
Check its installation status, platform support, and dependencies in Skill Store.
The agent is still waiting or the task failed
Open Task Management to distinguish queued work from a failure. For media tasks, use the reported reason to check the source link, browser dependencies, or a required platform sign-in.
