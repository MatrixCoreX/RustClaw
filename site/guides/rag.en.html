Import and query a $brand RAG knowledge base

Import product manuals, FAQs, and procedures in Memory → Knowledge base. Retrieval-augmented generation (RAG) lets the agent find relevant passages and cite them in replies. Long-term memory, also on the Memory page, stores details from conversations such as preferences and facts.

Download a sample or prepare your own files

The sample Returns Handbook includes instructions for requesting a return and a rule about who pays return shipping for defective items.

Download the sample Returns Handbook (Markdown)

You can also import text, Markdown, PDFs with selectable text, and Office documents such as DOCX, XLSX, and PPTX. For a scanned PDF, run OCR first and import the searchable copy.

Put the file where the agent service can read it. For a remote deployment, copy it to that device or to a folder mounted there that the service is allowed to read. Relative paths are resolved from the agent’s workspace.

Import the file and search for a passage

  1. Open Memory → Knowledge base → Add material. Enter Returns Handbook as the library name. If you saved the sample in the workspace’s docs folder, enter docs/returns-handbook.md as the path. Enter one file or folder path per line when adding multiple sources.
  2. Select Start adding and wait for processing. If Continue unfinished work appears, use it to process the next batch before refreshing the library list.
  3. Select Refresh libraries, choose the library, and use View document status to check that the file is listed. Under Search material, search for return shipping and check that the excerpt mentions the seller covering it.

Ask in Agent chat and verify the source

Name the library in your first question and ask for a citation. When the library is clear from the current conversation, you can ask a follow-up directly. If several libraries could contain the answer, name the one you want the agent to search.

A citation may include a section, page, or worksheet, depending on the document. Use that location or find the passage in Search material to verify both the rule and the conditions under which it applies.

Try three questions with the sample handbook

  1. Find a stated rule
    “In the Returns Handbook, who pays return shipping for a defective item? Cite the policy.”

    The reply should say the seller pays once customer support confirms the defect and cite section 3.2.

  2. Ask the same thing in different words
    “Support has confirmed the item is defective. Do I need to pay the courier to send it back? Please cite the Returns Handbook.”

    The reply should find the same section and preserve the condition that support has confirmed the defect.

  3. Ask for a detail the handbook does not cover
    “How many days after the warehouse receives a return must the refund be issued? Answer using only the Returns Handbook.”

    The reply should say the handbook does not specify a refund deadline.

When an import stalls or a passage is missing

The task is queued or processing
Queued means the task is waiting to start. Working means the current batch is running. If it takes longer than expected, use the task ID shown in the panel to check its status in Tasks. If the panel offers Continue unfinished work, finish the remaining batches before refreshing libraries.
The library is missing from the list
Check that you’re signed in to the same account and deployment used for the import, then select Refresh libraries. Each deployment stores its own imported documents.
The search finds no matching passage
Check View document status and search for words from the original. Open Diagnostics for skipped-file or parsing details. Check the path and permissions on the service host, or use a searchable copy of a scanned PDF.
The source file has changed
Run Add material again with the same library name and file path to update that file. To process all recorded sources again, select Rebuild library index. Check the document status and repeat your search afterward.
