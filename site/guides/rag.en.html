Prepare documents that the agent service can read

Start with a small text or Markdown file, a PDF with selectable text, or an Office document such as DOCX, XLSX, or PPTX. For scanned PDFs, run OCR first and import the resulting searchable text.

Use paths the agent service can read on its host. For a remote deployment, put the files on that device or in a folder mounted there. Relative paths are resolved from the agent service's working directory.

To try the walkthrough, save this sample policy as returns-handbook.md in a folder the service can read.

## 3.2 Defective-item returns
If customer support confirms a product defect, the seller covers return shipping.

Import a named library and verify the contents

  1. Open Memory → Knowledge base → Add material. Set the library name to Returns Handbook and enter a file or folder path on each line.
  2. Select Start adding. Wait for processing, and use the continuation button if the console offers to resume unfinished work.
  3. Select Refresh libraries, choose the library, and check its document status. In Search material, search a phrase that appears in the file to verify a matching passage and its source.

Ask a question and request a citation

In Agent chat, name the library, ask a specific question, and request the source. A result can cite a chapter, page, or another location that the imported file provides.

“In the Returns Handbook, who pays return shipping for a defective item? Cite the policy.”

The sample reply cites the handbook section that supports the answer. Open the cited passage and check that it contains the same conditions and rule.

When a library or passage is missing

The library is missing from the list
Check that you're signed in to the same account and deployment used for the import, then refresh the libraries. Each deployment stores its own imported documents.
The search finds no matching passage
Verify the document status, search for a phrase from the original, and check parsing warnings. For a scanned file, use a searchable copy.
The source file has changed
Keep the updated file at its recorded path and use the library rebuild action to process that source again. Check the document status after the rebuild.
