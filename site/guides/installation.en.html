Install on Ubuntu

Run the checks on the Ubuntu PC or server. For x86_64, confirm that the installer selects a tag beginning with ubuntu-x86_64-. The installer registers systemd startup.

Install on macOS

Open Terminal on the Mac. An Apple silicon Mac running Terminal natively reports arm64 and uses macos-aarch64-. An Intel Mac reports x86_64 and uses macos-x86_64-. The installer registers a LaunchAgent for your account.

Verify and run the installer

Verify and install the signed release

Download the installer from the project’s GitHub repository. Run --check-only to see which package it selects before you install.

curl -fL -o install-latest-release.sh \
  https://raw.githubusercontent.com/$release_repository/main/install-latest-release.sh
bash install-latest-release.sh --repo $release_repository --check-only

Compare the selected tag with the table. If it matches, run the installer. It verifies the signed release and checksums, installs to ~/agent-runtime by default, and starts the services.

bash install-latest-release.sh --repo $release_repository
"$$HOME/.local/bin/agentctl" -status
"$$HOME/.local/bin/agentctl" -health

Open the web console and run a first task

  1. Open http://127.0.0.1:8788 on the machine running $brand. If you installed on a remote server, use SSH port forwarding from your own computer.
  2. Find the initial sign-in details in data/bootstrap-credentials.txt inside the install directory. Sign in and change the initial password.
  3. Open Models, save and test a text model, then open Agent and send a short prompt. A reply confirms the console, service, and model are working together.
