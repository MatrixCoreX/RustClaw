导入和使用 $brand 的 RAG 知识库

在记忆管理 → 知识库导入产品说明、常见问题或业务流程。RAG（检索增强生成）让 Agent 能检索相关段落，再根据原文回答并给出处。同一页面里的长期记忆用于保存对话中形成的偏好和事实。

准备文件 导入并验证 提问和引用 三道测试题 排查问题

下载演示手册或准备自己的资料

演示《售后手册》写明了申请退货要提供的信息，以及商品有质量问题时的退货运费规则。

下载演示《售后手册》（Markdown）

也可以导入纯文本、Markdown、能选中文字的 PDF，以及 Word（DOCX）、Excel（XLSX）和 PowerPoint（PPTX）文件。扫描版 PDF 可以先做 OCR，再导入识别后的可搜索版本。

把文件放到 Agent 服务有权限读取的位置。服务部署在另一台设备时，先把文件放到服务端或它能读取的挂载目录。相对路径以 Agent 的工作区为基准。

导入文件并搜索一段原文

  1. 打开记忆管理 → 知识库 → 添加资料，资料库名称填售后手册。如果把演示文件放在工作区的 docs 子目录，路径就填 docs/returns-handbook.md。添加多份资料时，每行填一个文件或文件夹路径。
  2. 点击开始添加，等待处理。出现继续未完成工作时，先处理后续批次，再刷新资料库列表。
  3. 点击刷新资料库，选中刚才的库，用查看文档状态确认文件已列出。然后在搜索资料中查「退货运费」，确认命中的原文写明由商家承担。

在 Agent 对话里提问并核对出处

第一次提问时写出资料库名称，并请 Agent 给出处。同一段对话里已经明确在查哪个库，可以直接追问。多个资料库都可能相关时，写明要查的库名。

引用可以包含章节、页码或工作表，具体取决于文件格式。根据引用位置查阅原文，也可以回到搜索资料查相应段落，核对条款的适用条件和结论。

用三道题验证售后手册的检索效果

  1. 查明确写出的规则
    「查《售后手册》。商品有质量问题时，退货运费谁承担？请给出处。」

    预期能答出客服核实质量问题后由商家承担退货运费，并引用第 3.2 节。

  2. 换一种说法再问
    「客服已经确认商品有质量问题，寄回去的快递费需要我出吗？请引用《售后手册》。」

    预期仍能找到第 3.2 节，并保留「客服已核实」这个条件。

  3. 问手册没有写的细节
    「仓库签收退货后，几天内发起退款？只根据《售后手册》回答。」

    预期说明这份手册未规定具体退款时限。

导入卡住、找不到资料或需要更新时

一直显示排队中或处理中
排队中表示任务正在等待执行，处理中表示当前批次正在运行。等待时间较长时，可用面板显示的任务编号到「任务管理」核对状态。出现继续未完成工作时，处理完剩余批次再刷新资料库。
列表里看不到刚导入的库
核对登录账号和控制台地址，再点刷新资料库。每台设备上的独立部署分别保存自己导入的资料。
文档存在，搜索却没有命中
先点击查看文档状态确认文件已列出，再试原文中的词。展开诊断信息查看文件是否被跳过或有解析提示，核对服务端路径和权限。扫描件可以换成 OCR 处理后的可搜索版本。
源文件有新版本
用相同的资料库名称和文件路径再次添加资料，就能更新这份文件。需要重新处理库里记录的全部来源时，点击重建资料库索引。完成后再查看文档状态，并重复搜索验证。
