导入和使用 $brand 的 RAG 知识库

在记忆管理 → 知识库导入产品说明、常见问题或业务流程。RAG（检索增强生成）让 Agent 能检索相关段落，再根据原文回答并给出处。同一页面里的长期记忆用于保存对话中形成的偏好和事实。

准备文件 导入并验证 提问和引用 三道测试题 七个实测案例 排查问题

下载演示手册或准备自己的资料

演示《售后手册》写明了申请退货要提供的信息，以及商品有质量问题时的退货运费规则。

下载演示《售后手册》（Markdown）

也可以导入纯文本、Markdown、能选中文字的 PDF，以及 Word（DOCX）、Excel（XLSX）和 PowerPoint（PPTX）文件。扫描版 PDF 可以先做 OCR，再导入识别后的可搜索版本。

把文件放到 Agent 服务有权限读取的位置。服务部署在另一台设备时，先把文件放到服务端或它能读取的挂载目录。相对路径以 Agent 的工作区为基准。

导入文件并搜索一段原文

  1. 打开记忆管理 → 知识库 → 添加资料，资料库名称填售后手册。如果把演示文件放在工作区的 docs 子目录，路径就填 docs/returns-handbook.md。添加多份资料时，每行填一个文件或文件夹路径。
  2. 点击开始添加，等待处理。出现继续未完成工作时，先处理后续批次，再刷新资料库列表。
  3. 点击刷新资料库，选中刚才的库，用查看文档状态确认文件已列出。然后在搜索资料中查「退货运费」，确认命中的原文写明由商家承担。

在 Agent 对话里提问并核对出处

第一次提问时写出资料库名称，并请 Agent 给出处。同一段对话里已经明确在查哪个库，可以直接追问。多个资料库都可能相关时，写明要查的库名。

引用可以包含章节、页码或工作表，具体取决于文件格式。根据引用位置查阅原文，也可以回到搜索资料查相应段落，核对条款的适用条件和结论。

用三道题验证售后手册的检索效果

  1. 查明确写出的规则
    「查《售后手册》。商品有质量问题时，退货运费谁承担？请给出处。」

    预期能答出客服核实质量问题后由商家承担退货运费，并引用第 3.2 节。

  2. 换一种说法再问
    「客服已经确认商品有质量问题，寄回去的快递费需要我出吗？请引用《售后手册》。」

    预期仍能找到第 3.2 节，并保留「客服已核实」这个条件。

  3. 问手册没有写的细节
    「仓库签收退货后，几天内发起退款？只根据《售后手册》回答。」

    预期说明这份手册未规定具体退款时限。

从商品导购到订单物流的 7 个 RAG 案例

下载并解压 8 份中文 Markdown 文档，把文件夹放到 Agent 服务能读取的位置。在记忆管理 → 知识库添加该文件夹，资料库名称填RAG 场景示例。导入完成后点刷新资料库，核对 8 份文档。

下载 8 份演示文档（ZIP）

每个案例各开一个新对话。对题目中未写明资料库的问法，在开头加上「请查『RAG 场景示例』，并给出出处。」第七个案例需要先接入订单演示 MCP。商品、活动、仓库和订单数据均为演示。

以下是本机中文对话的实测摘要。七条回复均核对了知识库检索记录和引用文档，订单案例还核对了 MCP 的查询结果。

  1. 商品导购 · 对比耳机规格

    轻舟耳机 A 款和 B 款有什么区别？哪款支持同时连接手机和电脑？

    B 款支持双设备蓝牙连接，单次约 8 小时，配充电盒约 32 小时。A 款连一台设备，单次约 6 小时，配充电盒约 24 小时。

    轻舟耳机规格表

  2. 活动运营 · 核对优惠叠加条件

    夏日周末专场的满减和店铺券能叠加吗？哪些商品参加不了？

    可以叠加。先扣店铺券，再判断是否达到平台满减门槛。预售定金、数字礼品卡和标记为清仓的商品均排除。

    夏日周末专场规则

  3. 仓库发货 · 把打包流程变成清单

    请查「RAG 场景示例」里的《玻璃杯打包 SOP》，把原文写明的发货前质检和打包步骤整理成逐项勾选的清单，文末写出来源文件名。

    先对单和检查杯口、杯身、杯底。每只包两层气泡膜，同箱用隔板分开，五层瓦楞外箱四周留至少 3 厘米缓冲。工字形封箱、贴易碎标签，核对订单号和运单号后出库。

    玻璃杯打包 SOP

  4. 新人培训 · 首次上架商品

    我是新来的运营，第一次上架商品要准备什么？按顺序告诉我。

    准备标题、类目、SKU、价格、库存和图片，再建草稿并填好运费与发货时效。主管复核通过后发布，最后从买家端测试规格切换、运费和购物车。

    电商运营新人手册

  5. 安装排障 · 树莓派网页打不开

    请调用 kb.search，在「RAG 场景示例」检索「树莓派装好后网页打不开，先检查哪些项目」。根据返回的片段列出前三个检查步骤，写出检查命令、本机地址、局域网检查项和来源文件名。

    先在树莓派检查服务状态和健康状态，再从本机测试默认端口 8788。本机正常时，再检查局域网地址、监听范围和防火墙。

    树莓派控制台排障示例

  6. 版本对比 · 查清发货流程改了什么

    青禾仓发货流程 v1.0 和 v2.0 的截单、核对、异常交接有什么变化？请引用两份文档。

    截单从 16:00 提前到 15:30。纸质单据核对改为扫描订单和商品条码。异常由收工前汇总邮件改为立即提工单，并暂停受影响的订单出库。

    历史版 v1.0 现行版 v2.0

  7. MCP 与 RAG 联动 · 订单物流和易碎品装箱

    请用 MCP 的 get_order_status 查询订单 3 的当前状态和快递单号，再检索「RAG 场景示例」中的订单 3 装箱单，告诉我这单是否要按易碎品打包并给出文档出处。

    本机演示的 MCP 查询返回订单 3 运输中，快递单号为 7898047967。知识库的装箱单列出两只雾白陶瓷马克杯，包装级别为 F2 易碎品，要求单独包裹、保护杯把并用隔板分开。

    使用本网站提供的 MCP 演示时，把问题里的工具名换成 lookup_order。两套示例对订单 3 使用相同的模拟物流状态和快递单号。

导入卡住、找不到资料或需要更新时

一直显示排队中或处理中
排队中表示任务正在等待执行，处理中表示当前批次正在运行。等待时间较长时，可用面板显示的任务编号到「任务管理」核对状态。出现继续未完成工作时，处理完剩余批次再刷新资料库。
列表里看不到刚导入的库
核对登录账号和控制台地址，再点刷新资料库。每台设备上的独立部署分别保存自己导入的资料。
文档存在，搜索却没有命中
先点击查看文档状态确认文件已列出，再试原文中的词。展开诊断信息查看文件是否被跳过或有解析提示，核对服务端路径和权限。扫描件可以换成 OCR 处理后的可搜索版本。
源文件有新版本
用相同的资料库名称和文件路径再次添加资料，就能更新这份文件。需要重新处理库里记录的全部来源时，点击重建资料库索引。完成后再查看文档状态，并重复搜索验证。
