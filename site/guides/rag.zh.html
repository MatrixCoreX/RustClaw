导入和使用 $brand 的 RAG 知识库

RAG 是检索增强生成。把产品说明、常见问题或售后手册导入一个命名资料库后，Agent 可以先查相关段落，再根据原文回答并给出处。

准备 Agent 服务能读取的文件

第一次可以用一份较小的 Markdown、纯文本、能选中文字的 PDF，或 DOCX、XLSX、PPTX 等办公文档。扫描版 PDF 可以先做 OCR，再导入识别后的可检索文本。

文件需要放在 Agent 服务能访问的路径上。服务部署在另一台设备时，把资料放到那台设备或它能读取的挂载目录。相对路径以 Agent 服务的工作目录为起点。

想跟着示例试一遍，可以把下面两行保存为 returns-handbook.md，放到服务能读取的目录里。

## 3.2 质量问题退货
客服核实商品存在质量问题后，退货运费由商家承担。

导入后检查文件是否能搜到

  1. 打开记忆管理 → 知识库 → 添加资料。资料库名称可以填售后手册，再逐行输入文件或文件夹路径。
  2. 点击开始添加，等待资料处理。如果页面提示继续未完成工作，按提示处理下一批。
  3. 点击刷新资料库，选择库名，用查看文档状态核对文件。接着在搜索资料里搜索原文中的关键词，比如「退货运费」，确认能命中片段和出处。

在 Agent 里指定资料库并要求给出处

提问时写清库名和你要核实的规则，并请 Agent 给出处。根据文件格式，引用可能指向章节、页码、工作表或其他原文位置。

「查一下《售后手册》，商品有质量问题时，退货运费谁承担？请给出处。」

示例回答给出了对应的手册章节。可以打开原文核对责任人、适用条件和条款是否一致。

找不到资料库或原文时

列表里看不到刚导入的库
核对登录账号和控制台地址，再点刷新资料库。各台设备上的独立部署分别保存自己导入的资料。
文档存在，搜索却没有命中
先看文档状态和解析提示，再试原文中的词。扫描件可换成 OCR 识别后的可搜索版本。
源文件有新版本
在已记录的路径上更新文件，再用资料库重建功能重新处理来源。完成后查看文档状态。
