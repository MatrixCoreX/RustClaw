Agent 技能、MCP 工具与 RAG 知识库

使用和安装 Agent 技能

技能让 Agent 能处理文件、提取文档内容或转写语音。你可以在聊天里直接描述想要的结果，Agent 会根据任务选择可用的技能。

「读一下我上传的 PDF，列出需要跟进的事项和截止日期。」
了解内置技能和按需安装的技能
  1. 在首页打开工具技能，查看已安装技能及其启用状态。
  2. 需要更多能力时，打开 Skill Store，查看技能支持的平台和依赖，再按需安装。
  3. 确认技能已启用，然后在 Agent 聊天里发一句具体的请求。

通过 MCP 接入外部工具

MCP（模型上下文协议）让 Agent 调用其他系统提供的工具。你可以连接一个或多个工具服务器，查询订单状态、物流等实时业务数据。

「订单 3 发货了吗？是哪家快递，单号是多少？」
了解 MCP 工具的权限控制
  1. 在管理控制台打开大模型 → 外部工具服务器，点击添加服务器。本机 stdio 服务填写启动命令和参数，远程 Streamable HTTP 服务填写地址。
  2. 核对连接信息，信任并启用该服务器，打开 MCP 总开关。在允许的工具里填写工具名称，再保存 MCP 设置。
  3. 如果页面提示需要重启，按提示重启服务。状态显示可用后，点击测试协议，再到 Agent 聊天去查一笔订单。

用 RAG 知识库查询自己的资料

RAG 是检索增强生成。导入运营手册、常见问题或售后流程后，Agent 可以先找相关段落，再根据资料回答问题，并引用对应的章节、页码等位置。

「查一下《售后手册》，商品有质量问题时，退货运费谁承担？请给出处。」
查看知识库导入和搜索指南
  1. 打开记忆管理 → 知识库 → 添加资料，给资料库起个容易记住的名字，比如售后手册。
  2. 逐行填写 Agent 服务能读取的文件或文件夹路径，再点开始添加。可以先试 Markdown、纯文本或可以选中文字的 PDF。
  3. 导入完成后刷新资料库，先用搜索资料检查能否找到原文。之后在 Agent 聊天里带上库名提问，并要求给出处。

在同一条消息里查订单和售后规则

接好订单查询工具并导入售后手册后，一条消息就可以同时查当前物流状态和书面退货规则。

「查一下订单 3 是否发货，再根据《售后手册》说明商品有质量问题时谁承担退货运费，并给出规则出处。」
