$brand 自托管 AI Agent

在树莓派、Ubuntu 或 macOS 上运行开源 AI Agent。你可以在网页控制台配置模型、上传文件和查看任务进度，也可以绑定 Telegram、微信或飞书，在常用的聊天软件里发起任务。

比如，发一份 PDF 请 Agent 提炼要点，用 MCP 查订单物流，或从 RAG 知识库找出售后条款并给出处。采集或下载的媒体结果，可以在技能配套的 AiAPP 里回看。

下载安装 查看使用指南

Agent 技能

启用技能后，可以用聊天指令处理文件、转写语音、采集和下载媒体，也能查询加密货币行情。

安装和使用技能

在 Agent 聊天里发起媒体采集和下载任务。下面两张截图来自媒体技能的配套 AiAPP，用于查看任务结果。

媒体采集技能

按关键词从小红书、抖音、哔哩哔哩等支持的平台收集帖子，保留作者文案、预览、来源链接和采集时能读取到的互动数据。可以只采一批，也可以在 Agent 里开启、暂停或停止持续采集。

「在小红书搜索『露营装备』，只采一批，最多 5 条，保留作者文案、预览和来源链接。」
试用媒体采集

媒体下载技能

把支持平台的作品链接或完整分享文案发给 Agent，就可以保存能获取到的原视频或原图。支持的图文作品还可以一并保存原文，图片较多时会打成 ZIP 文件。

「帮我保存这条小红书图文的原图和能获取到的正文：[粘贴分享链接]。」
试用媒体下载

加密货币行情技能

在 Agent 聊天里用 crypto 技能查询公开行情。

「帮我查询比特币（BTC）的最新美元报价，并注明数据来源和查询时间。」
试用加密货币行情查询

AiAPP 技能配套界面

技能可以在 AiAPP 提供配套界面。管理员可以在里面筛选采集记录、打开原帖，也能回看下载任务和提取的附件。

了解 AiAPP 安装入口和界面设计

MCP 工具

连接外部系统提供的工具，让 Agent 查询订单物流、快递单号等实时业务数据。

「订单 3 到哪儿了？请告诉我快递单号。」
配置和测试 MCP 工具

RAG 知识库

导入产品说明、常见问题和售后手册，让 Agent 搜索原文并在回答中给出处。

「查一下《售后手册》，商品有质量问题时谁承担退货运费？请给出规则出处。」
导入资料并提问

安装到你的设备

选择设备查看对应的安装说明。安装后打开网页控制台配置模型，就可以发送第一条消息。
