在 Raspberry Pi 上安装 $brand

如果你的树莓派已经装好 64 位 Raspberry Pi OS，可以直接下载签名发布包。接下来会确认系统架构、运行官方安装脚本，再打开网页控制台发送第一条消息。

安装前检查 下载并安装 打开网页控制台 常见问题

安装前检查

在树莓派上的终端运行以下命令。你也可以先用 SSH 登录树莓派，再在该会话中执行。

uname -m
getconf LONG_BIT
python3 --version
df -h "$$HOME"
  • 前两行应显示 aarch64 和 64。若装的是 32 位系统，可以用 Raspberry Pi Imager 将 Raspberry Pi OS (64-bit) 写到另一张存储卡，再用它启动兼容的树莓派。
  • 需要 Python 3.11 或更新版本，以及 Bash、curl、tar 和 OpenSSH 的 ssh-keygen。如果缺少 curl 或 ssh-keygen，可在 Raspberry Pi OS 中执行 sudo apt update，再执行 sudo apt install ca-certificates curl openssh-client。
  • 检查最后一行的可用空间。以已核对的 pi-aarch64-c785c9dc6a38 发布为例，压缩包约 789 MiB，安装时还要留出解压和部署空间。

Raspberry Pi Imager 官方使用说明

下载并安装

把官方安装脚本下载到当前目录，再用 --check-only 查看脚本选中的版本。

curl -fL -o install-latest-release.sh \
  https://raw.githubusercontent.com/$release_repository/main/install-latest-release.sh
bash install-latest-release.sh --repo $release_repository --check-only

看到发行标签以 pi-aarch64- 开头后，运行安装命令。

bash install-latest-release.sh --repo $release_repository

脚本会选择适配当前系统架构的发布包，在安装前检查签名和校验信息。默认安装目录是 ~/agent-runtime，服务会在安装后启动。安装结束后，检查运行状态。

"$$HOME/.local/bin/agentctl" -status
"$$HOME/.local/bin/agentctl" -health

查看 GitHub 发布列表 · 发行安装、签名校验与更新说明

打开网页控制台

在树莓派自己的浏览器中打开 http://127.0.0.1:8788。如果你从另一台电脑访问，并且已有树莓派的 SSH 登录权限，在那台电脑的终端运行以下命令，再在那台电脑的浏览器打开 http://127.0.0.1:18888。将示例中的用户名和 IP 换成你的实际值。

ssh -N -L 18888:127.0.0.1:8788 YOUR_PI_USER@YOUR_PI_IP
  1. 首次初始化完成后，在树莓派上查看安装目录中的 data/bootstrap-credentials.txt 获取登录信息，并在账号管理里更改初始密码。
  2. 打开「大模型」，配置并保存一个可用的文本模型。需要 API Key 的模型请按页面提示填写并测试连接。
  3. 打开「Agent」，发送「请用一句话介绍你能做什么」。看到回复后，浏览器、后台服务和模型调用这条链路就跑通了。

常见问题

脚本提示没有匹配的发布包
重新核对系统位数和架构，并在 GitHub Releases 查找 pi-aarch64- 标签。Pi 小屏组件有单独的包，完整服务应选 Pi ARM64 发布。
网页打不开
先运行上面的状态和健康检查，确认网页入口服务已启动。跨设备访问时，也检查 SSH 转发窗口是否仍在运行。
打开了控制台，但消息一直在等待
先在「大模型」确认模型可用，再打开「任务管理」看这一条任务是排队、运行中还是失败。

本指南的安装参数和默认端口已按项目安装脚本核对，并校验了上述 ARM64 发布的清单签名。设备上的安装结果以实际运行状态和健康检查为准。
