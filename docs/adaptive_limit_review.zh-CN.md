# 有界视图与资源安全

上限检查是一条代码审查防线，不意味着所有上限都应删除。任务预算、页面预览、
输入校验、存储配额与解析器安全限制分别由不同组件负责。

## 当前边界

- 教学证据按页展示，完整引用可展开查看；分页不能删除后续记录。
- KB/AiAPP 对不可信展示字段做长度限制，不能据此修改原始文档或任务结果。
- 文档摘要的 16 字符前缀只用于可读标识；校验和授权仍使用完整摘要与所有权。
- 模型日志的解压长度、声明长度与 SHA-256 必须同时通过。超出编码预算的原始
  记录不压缩；生产任务不能依赖诊断日志回查历史执行。
- 恢复调度每次只扫描有限候选，扫描游标会越过无效前缀并在队列缩小或重启后
  回绕。单次扫描上限不能成为整个任务的工作量上限。
- 代码索引限制缓存读取、单文件解析时间、输入大小和 AST 条目数；返回明确的
  部分状态与范围读取入口，不能把“文件扫描完成”说成“符号分析完整”。
- 历史任务证据使用任务独占的不可变对象和摘要绑定清单。读取先做当前授权，
  再验证大小和摘要，只加载明确选中的对象。配额或存储失败必须明确报告，
  不能重做已完成操作，也不能因此把真实完成的操作改成失败。
- 大 JSON 的结构化预览最多 8 KiB：保留脱敏后的短标量及长字符串的字节数，
  标记为不完整的数据视图。完整 artifact、摘要与范围读取入口保持可用；
  runtime 不解析预览里的自然语言来决定路由、重试或成功。
- KB 的单轮导入量有可恢复 checkpoint；输入越界明确拒绝，存储配额超限时
  事务回滚。文档分页使用额外一行判断后续游标，不能丢弃该行对应的数据。
- 超大提取文档使用稳定错误原因，不能把未标注的文本前缀当成完整文档入库。
- 大 Rust 文件的行候选索引复用单片段、源码字节和 AST 条目配额，限制单行、
  符号名合计字节和符号数量；同一文件描述符单遍计算完整摘要。超长或非法
  UTF-8 行整体跳过，保留后续准确行号，并明确返回部分索引状态，不能把截断
  前缀当完整定义。边界测试见 `large_rust_source_tests.rs`。
- 独立编程验收仅在只读、断网沙箱执行生成代码；stdout/stderr 分别使用内核
  64 KiB 文件上限，命令最长 60 秒。输出越界明确验收失败，不无限捕获输出，
  也不把截断结果算通过；这些是测试监督边界，不是生产 agent 的任务预算。

具体源码边界和对应测试见 [审查清单](adaptive_limit_review.md)。新增基线条目必须
逐项解释并有边界测试，不得整体重新生成基线来忽略无关告警。静态检查通过、
离线测试通过、真实 NL 验收和实际部署是四种不同证据，不应混为一谈。
