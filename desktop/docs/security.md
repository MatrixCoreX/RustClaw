# 桌面安全合同

## 本机权限

- 主窗口仅运行打包 UI，导航限于本机首页。原生 IPC 使用显式 Tauri AppManifest 和 capability；没有通用 shell、文件系统、HTTP plugin 或任意命令转发。
- 所有主窗口命令再次检查 WebView label。AiAPP 使用不同窗口，只允许 `aipp_context`、`aipp_bridge`；在 Linux 无法按 iframe 区分 IPC 的情况下，它仍然不能得到主窗口命令。
- 文件保存由本机对话框选择路径。远端文件名仅作为清理后的建议，远端路径不能成为本机文件路径。
- 私钥签名继续复用原 UI 的内存签名代码。资产私钥不进入设备 profile、原生记住登录、日志或更新配置。

## 网络与认证

- renderer 只传 session UUID、相对 API 路径、方法和受限 headers。native 固定 origin、凭据、Cookie jar、CSRF 和连接代次。
- HTTPS 最低 TLS 1.2，不使用代理环境变量，不跟随重定向，不降级 HTTP。私有 CA profile 只使用该 profile 的信任根，仍验证完整证书链、主机名与有效期。
- SSH 先验证固定主机指纹，再认证；只建立远端 loopback direct-tcpip，不调用 shell，不读取 SSH 配置，不开放 SSH 本地代理端口。
- API Key 与 Cookie/CSRF 留在原生内存。`auth/me` 中的当前用户 Key 被去掉；管理员主动读取的账户管理内容仍服从原服务端 API 合同。
- 只有用户勾选记住登录时才写系统安全存储。凭据库失败不会写明文替代。
- 断开连接销毁原生 session、流与下载授权；页面全量重建，旧 JS realm 的响应与签名状态不能进入新设备页面。已提交写请求不会自动重放。

## 局域网发现

- 自动发现只浏览中性 `_agent-runtime._tcp.local.` 服务；拒绝非 `.local` 主机名、非法标签、非内网 IPv4、零端口和不兼容协议声明。当前自动发现的地址族是 IPv4，IPv6-only 设备需手工添加。
- 主动扫描由主窗口的显式点击发起。仅物理 LAN 接口、RFC1918 地址、当前至多 /24 范围，最多 508 个地址 / 24 并发 / 20 秒；取消后丢弃正在进行的请求。接口枚举使用跨平台库，Linux / macOS 使用各自适配器筛选，不支持的系统返回不可用。
- 探测客户端与连接客户端完全分离，不读取 profile / Cookie / 密钥，不使用环境代理，不跟随跳转。固定匿名 GET `/webd/session`，单个响应最多 4 KiB / 1.2 秒；必须匹配未登录的结构化合同，之后才探测固定的 443 / 22 端口。
- 广播、IP、服务响应和开放端口只是未经验证的候选信息，永远不用于信任授权。连接仍执行原有 CA 摘要、证书链、有效期、主机名和 SSH 主机公钥校验。切换发现结果会清空配对证书、指纹及确认状态。
- 发现与取消 IPC 均仅主窗口可用；AiAPP 无权扫描网络。发现过程不会建立已登录会话或输出凭据。

## 传输与内容

- IPC 上传块上限 64 KiB，原生上传队列长度为 4；响应通过 pull 读取，每次最多 64 KiB。SSE 不会等待整个响应结束。
- 连接建立与无响应有超时，活跃大文件上传不会按总时长中止。关闭客户端不调用远端任务取消 API。
- Ubuntu WebKitGTK 拒绝自定义媒体 scheme，因此音视频使用独立的回环媒体 relay，只监听 `127.0.0.1` 的随机端口。主窗口申请的 244 位随机令牌绑定一个 session 和一个 artifact / preview，最多 8 个令牌，3 小时后到期；关闭预览或断开 session 撤销。GET / HEAD 以背压流式转发，Range 保留，不把完整大文件搬入 JSON 或 Vec。
- 媒体 relay 拒绝错误 Host、非打包 origin、写方法和查询参数，不提供通用 API、文件路径或 URL 代理，也不输出访问日志。未提供正确令牌的请求仅返回 403；HTML 等内容强制 sandbox CSP，前端 CSP 只允许音视频使用该回环地址。没有开放到 LAN 的明文管理服务。
- AiAPP 静态资源继续使用原生 `device:` 协议，每份资源上限 8 MiB；主窗口不能把 AiAPP 通道当作任意读取入口。
- AiAPP 每次资源读取由服务端检查安装状态、receipt 和 generation；bridge 还复核目录中的包版本与声明能力。现有目录 API 尚未公开原始 receipt/generation，不能宣称客户端额外固定了未提供的元数据。该项须在服务端有对应协议时再增加客户端校验，不能自行读取远端文件。
- AiAPP 禁止网络、表单、嵌套框架、本机文件与未声明能力。每窗口最多 4 个 bridge 操作，最多 8 个应用窗口。

## 发行范围

此版本是 Ubuntu 内部测试产物。未经验证的实际 LAN 拓扑、证书轮换、真实设备全部业务操作、系统休眠、输入法、音视频设备和系统凭据库状态不标记为通过。测试不会执行真实账户的交易、解绑、删除或部署。

## 本机 HTTP（0.2.1）

本机连接独立使用 `local` 类型，只接受 `http://127.0.0.1[:port]` 和 `http://[::1][:port]`，不通过 DNS 解析，不使用代理或跟随重定向。局域网 HTTP 仍被拒绝。凭据只经过原生传输，保留账户认证、CSRF、会话隔离与登出失效。本机 HTTP 信任当前操作系统和本机服务，不提供 TLS 对端认证。安装检测只返回存在提示，不执行发现的文件或自动启动服务。
