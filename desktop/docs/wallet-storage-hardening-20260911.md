# 本地资产账户保存加固（0.3.5）

本轮只改桌面工程，不更换密钥、不改账户公钥，不修改设备或资产服务端。原有 v1 密钥库、系统凭据库命名空间和加密备份格式保持不变，无需迁移账户。

## 已实施

- **导出必须重新验证密码。** 即使管理窗口已经解锁，导出加密备份仍须在原生安全窗口重新输入密钥库密码。新备份密码只控制备份文件，不能代替账户持有人的验证。原生命令强制执行该规则，错误密码不写出文件；开始验证后的导出无论成功或失败，都会清除解锁密钥。在文件选择器取消时不执行导出。
- **解锁有固定期限。** 每次解锁最多五分钟，创建、恢复、备份等操作不会延长这一时限。关闭安全窗口也会锁定密钥库并撤销待确认操作；原有离开应用、Ubuntu 锁屏和休眠中断锁定继续保留。窗口失焦时清除页面中的密码输入。
- **限制连续猜测。** 密钥库密码验证失败后，等待时间按 2、4、8、16、32、60 秒增加，最高一分钟。界面显示剩余时间；正确验证后恢复正常。签名、备份确认和管理解锁共用此限制。
- **收紧本地文件。** Linux/macOS 的密钥库目录为 0700，密钥库、操作记录和锁文件为 0600；读取旧私有文件时按已打开的文件句柄修正权限。私有文件必须属于当前用户且只有一个硬链接。拒绝符号链接、异常文件类型和被替换为链接的锁文件。读取使用不跟随链接的打开方式，并限制大小；写入继续采用临时文件、刷盘和原子替换，超限失败保留旧文件。
- **保留加密边界。** 私钥仍使用随机主密钥和 XChaCha20-Poly1305 加密；主密钥包装仍使用 Argon2id（64 MiB、3 次、4 路）及系统凭据库。密码及明文私钥不持久化，不通过 IPC 返回私钥。每笔交易仍单独验证密码。

## 实际边界

这是软件密钥库，不能保证抵御已控制当前操作系统账户或内核的程序。进程内密码等待不是离线防破解保证；完整加密备份被复制后，仍依赖备份密码强度和 Argon2id。没有新增防交换内存或崩溃转储承诺，也不能把公开账户名称和公钥当作保密存储。

Windows 增加文件句柄的 reparse-point 拒绝检查，仍使用用户应用目录继承的 ACL；本轮不声称已完成 Windows/macOS 原生验收。已安装 Apple Rust target 的交叉检查遇到宿主 C 编译器不支持 `-arch` / macOS target 参数，记录在验收目录；Ubuntu 的通过结果不替代其他平台测试。

恢复和备份文件允许用户显式选择位置，外部目录的访问控制由其文件系统决定。不要把加密备份和密码放在同一位置。验证错误时保留原文件，不自动重建或清空密钥库。

## 验证记录

本轮证据目录：`desktop/test-results/wallet-hardening-0.3.5/`。安装包的最终构建、测试和本机安装状态以 `desktop/installers/0.3.5/linux/validation.json` 为准。

验证覆盖：已解锁状态下错误密码不能导出、导出后锁定、旧 v1 格式恢复、固定解锁时限、连续失败等待和成功重置、文件权限修正、链接/异常文件拒绝、超限写入不破坏旧文件，以及原生窗口的备份与关闭行为。

原生窗口关闭用隔离 X 显示中的 `WM_DELETE_WINDOW` 事件验证。WebKitWebDriver 的 `DELETE /window` 在当前 Wry 中只销毁内嵌 WebView，不会触发 GTK 外层窗口关闭，不能替代这项验收。密码等待测试同时检查倒计时文字、按钮禁用和恢复可提交。

设计依据：[OWASP 敏感操作重新认证](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)、[OWASP 加密存储](https://cheatsheetseries.owasp.org/cheatsheets/Cryptographic_Storage_Cheat_Sheet.html)、[Rust 文件打开标志](https://doc.rust-lang.org/std/os/unix/fs/trait.OpenOptionsExt.html)。这些资料不是本实现的独立安全审计结论。
