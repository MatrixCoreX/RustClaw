# 桌面账户选择位置修正（0.3.1）

日期：2026-09-11。修改范围仅 `desktop/`，网页 UI 和后端源码不变。

- 移除页面顶部单独的账户工具栏。硬件账号模式通过桌面构建适配，在网页原有 JSX 位置放入统一账户选择组件；网页选择器结构变化时构建明确失败。
- 资产页：账户选择放在第一张资产总览卡片的分隔线下方。
- Bancor：账户选择放在交易面板内、余额上方；本地账号模式复用网页的行情/交易响应式分栏。
- 两种账号模式均保留完整公钥和复制按钮，复用网页 `NniPublicKeyDisplay`，切换账号时更新公钥和复制反馈。
- 管理本地账号、锁定、账户跨页选择、余额查询及原生签名流程继续保留。

验证：桌面 TypeScript 检查、9 项单元回归、UI 构建通过；产品身份自检/inventory、双品牌 UI、MCP 合同自检与主检查通过。Ubuntu 原生旧功能回归 20 项通过。

新增原生界面验收覆盖资产/Bancor 两页、1280/900 两种窗口宽度、浅色/深色主题、两个本地账号与硬件账号，共 12 次实际点击复制按钮并读取 X11 剪贴板，核对复制的完整公钥。检查每页只有一个账户选择器、所在总览/交易区域正确、无页面横向溢出。原生密钥库、备份恢复、独立确认与签名、重复提交限制、未知结果查询和失焦锁定也通过。

首次运行在复制时遇到 WebKit 自动化响应连接中断。测试处理为不重复点击、只检查完成反馈和实际剪贴板；复核通过。截图中的余额和交易均来自隔离协议夹具，不涉及实际资金。
