# 0.1.3 导航和下拉框显示修复

本次只修改 `desktop/`。共享 `UI/` 源码以及 Pi 的服务、账户、交易配置、HTTP / HTTPS 配置均未修改。

## 已复现的问题

在已安装的 0.1.2 上，用真实 Ubuntu WebKitGTK 窗口和独立本地 HTTPS 测试设备复现：

- 顶部设备栏高 42px，控制台页头底部位于 107px，但侧栏仍从 64px 开始，导航折叠按钮被遮住，鼠标命中测试失败。滚动后控制台页头还会移到设备栏下面。
- 交易账户原生 select 的计算样式是浅色文字、半透明深色背景，但 GTK 实际绘制为浅色背景，未点击时文字几乎不可见。仅检查 DOM 文本或 CSS 颜色不能发现此问题。

修复前截图和几何记录保存在 `test-results/layout-fix/before/`，失败回归记录在 `test-results/layout-fix/baseline-e2e.log`。交易账户来自本地测试设备公开配置，没有读取真实账户或发送交易。

## 处理

- 桌面构建适配器给共享布局增加桌面专用标记和测量 hook。ResizeObserver 按设备栏和页头实际高度同步导航起点、可用高度，适应窗口和字体大小变化；不改写共享源码。
- 普通页面滚动时页头停留在设备栏下方；聊天页的固定高度扣除设备栏，保留完整输入区域。设备栏层级调整为普通页头之上、对话框之下。
- 桌面控制台所有原生 select 统一使用主题前景、实色背景和 color-scheme，关闭 GTK 对收起状态的默认外观绘制。单选下拉框保留箭头，列表和多选框不增加箭头，继续使用原生选项菜单和键盘交互。

## 验证入口

- `tests/layout_e2e.py` 随原生端到端测试执行：真实导航命中、折叠和展开、滚动、字体增大、1280×860 / 1050×650 / 860×600 窗口、紧凑导航与聊天高度；交易账户和日志下拉框双主题截图；原生键盘选择。
- `test-results/layout-fix/` 保存本次前端测试、产品身份检查、原生验收与发布记录。
- 版本安装包及摘要以 `releases/release-manifest.json` 和 `releases/SHA256SUMS` 为准，历史安装包保留。
