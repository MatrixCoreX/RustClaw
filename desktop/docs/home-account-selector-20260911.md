# 首页本地账户下拉与统一入口（0.3.7）

首页将多个本地账户卡片合并为一个下拉框，选项显示“桌面本地账号 · 自定义名称 · 简写公钥”。下方展示当前所选账户的完整公钥、复制按钮与备份状态。切换账户沿用原生账户选择流程；选择成功后更新显示，切换过程中禁用入口，避免进入错误账户。公钥复制反馈在账户切换时重置。

首页只提供一个“进入资产”入口。进入工作区后继续使用顶部的“资产 / 转账”和“Bancor 交易”导航。没有账户时仍可创建或恢复；管理本地账号、加密备份等功能保留。

通过桌面构建适配器移除 Bancor 页“获得奖励”按钮，浏览器 UI 源码不变。资产页原本没有奖励按钮，其“管理账户”按钮继续用于管理账户。两个页面的账户选择位置、复制、余额、流水、转账、买入/卖出和原生签名流程保持原有实现。

本次只修改 `desktop/` 内的前端、构建适配、版本信息、既有验收脚本和说明文件；原生账户库格式、网络协议、私钥保存和签名逻辑没有改动。

Ubuntu 安装包、源文件摘要和验收记录位于 `desktop/installers/0.3.7/`。原生验收使用临时账户与隔离系统凭据库，检查下拉选择、完整公钥复制、备份状态、单入口到两个页面、奖励按钮不存在、浅深色主题及模拟资金操作。既有 0.3.6 安装包和验证记录保留。

验收完成：11 项 TypeScript 测试、类型检查、产品身份自检/清单与双品牌 UI 检查通过；实际 Ubuntu 安装包通过 6 组原生流程，包括账户切换、复制、单入口导航及隔离账本的转账、买入、卖出。已在本机安装并打开 0.3.7，账户库、设备连接资料和资产节点设置的 SHA-256 在安装前后保持一致。结果见 [验证记录](../installers/0.3.7/linux/validation.json)。

## 0.3.8：账户数量与 Bancor 入口

首页下拉选项显示“桌面本地账号（共 N 个） · 自定义名称 · 简写公钥”，收起时也能看到本机账户总数；标题数量同步显示“共 N 个”。数量直接来自账户列表。

资产页原“交易”入口和工作区导航统一显示“Bancor”。桌面构建适配器移除 Bancor 页 APR 按钮，交易表单、流水中的交易用语保留。此修改仍仅位于 `desktop/`；浏览器 UI 源码、账户库和签名逻辑未改动。既有版本及验收记录保留。

0.3.8 验收完成：类型检查、11 项 TypeScript 测试、产品身份自检/清单和双品牌 UI 检查通过；实际安装包通过 6 组原生验收，覆盖账户数量、账户切换与复制、新 Bancor 入口、APR/奖励按钮移除和隔离账本的转账、买入、卖出。浅色与深色截图已检查。已在本机安装并打开 0.3.8，安装前后账户库、设备连接资料和资产节点设置的 SHA-256 一致。详情见 [0.3.8 验证记录](../installers/0.3.8/linux/validation.json)。

## 0.3.11：限定到独立资产入口

修正此前适配范围过大：只有首页“进入资产”的独立工作区将资产页入口显示为 Bancor，并隐藏 Bancor 页 APR 与奖励按钮。从设备列表连接登录后，资产页恢复“交易 / Trade”，Bancor 页恢复原网页 APR 和奖励入口及导航回调；切换到桌面本地账户仍保留这些设备页面入口。

范围由独立工作区提供的 React context 明确指定，默认使用设备页面表现；不根据选中的账户类型推断，也不修改网页 UI 源码。首页和账户安全窗口的语言按钮移到外观按钮旁边。

0.3.11 已通过类型检查、11 项 TypeScript 测试、产品身份自检/清单及双品牌 UI 检查。实际 Ubuntu 安装包通过 16 组原生验收，覆盖两类入口、设备页面在硬件/本地账号下保留“交易 / APR / 奖励”、APR 打开与返回、独立工作区隐藏 APR/奖励及模拟交易。中英文首页、深浅色和原生安全窗口截图已检查。已安装并打开，账户库、设备资料及节点配置摘要保持一致。见 [0.3.11 验收记录](../installers/0.3.11/linux/validation.json)。
