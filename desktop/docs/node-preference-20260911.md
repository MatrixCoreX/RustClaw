# 资产节点优选与外观（0.3.9）

进入本地资产工作区时自动检查已保存的节点，在同一账本的可用节点中优先连接本轮响应时间较短的节点。顶部显示“已优选 / 手动选择”及本轮响应耗时，并提供“优选节点”按钮。页面内原有的手动选择、添加节点和复制公钥功能保留。手动选择在本次工作区使用期间保持，重新进入工作区或点击优选按钮会重新检查。

优选由原生端执行，测量资产和 Bancor 两个 capabilities GET 请求从连接到完整响应校验的总耗时，包含 DNS、TCP、TLS 和服务响应。只检查已保存的节点，最多同时检查 8 个；单节点 4 秒、整轮 6 秒上限，超时后取消尚未完成的检查。它表示本轮连接响应速度，不是带宽或长期可用性保证。节点失败不会将 HTTPS 降级为 HTTP；仍仅允许数字回环地址使用本机 HTTP。

选中的节点必须通过原有证书、协议版本、服务类型、原点和账本一致性检查。优选不发送账户地址、密码、私钥或交易，只读取能力合同。已有账本标识保存在节点配置的可选 `ledger_id` 中；旧配置缺少该字段时可直接读取，首次成功连接后补充。首次优选以原选中节点的账本为依据；原节点不可用且响应的节点属于不同账本时，要求手动选择，不猜测账本。手动选择其他账本后，以该次明确选择为后续优选依据。

节点切换与交易准备、确认共用原生操作锁。有待确认或已提交但结果待核实的操作时，优选返回明确提示，保持原节点和操作状态。选择失败保留原会话及保存的选择；仍选中当前节点时复用原会话。成功切换到其他节点才沿用已有的锁库、撤销旧连接和清理确认流程。交易期间没有定时自动换节点，也不重放资金操作。

首页、本地资产工作区和账户安全窗口的外观按钮改为太阳/月亮图标，保留提示及屏幕阅读器标签。没有已保存外观时默认深色；已有浅色/深色选择继续生效。浏览器 UI 源码未修改。

语言与网页 UI 保持一致，提供中文/英文，沿用 `appStorageKey("monitor.lang")`。共享页面继续使用其已有的双语 `t(中文, English)` 文案与 `productCopy` 产品展示替换；桌面专有元素通过 `frontend/i18n/en.json` 补充译文。首页、登录、设备发现、节点选择、资产、Bancor 和原生账户管理/签名确认窗口共享语言设置，切换后跨窗口同步并持久保存。日期使用相应语言的区域格式。账户名称、公钥、金额和签名协议字段不参与翻译。语言切换不重新选择账户或节点，也不修改待确认交易的签名载荷。

所有改动位于 `desktop/`。Ubuntu 安装包和验收结果位于 `desktop/installers/0.3.9/`；历史发行包及构建缓存保留。节点配置新增字段由 0.3.9 读取，旧版严格解析器不识别该字段；账户密钥库格式不变。

验收完成：14 项 Rust 资产测试、11 项 TypeScript 测试、类型检查、产品身份自检/清单及双品牌 UI 检查通过。实际 Ubuntu 安装包通过 9 组原生资产验收与 10 组登录/共享控制台验收，包含快慢节点、账本隔离、失败保留会话、待确认与未知结果保护、中文/英文跨窗口同步、默认深色和外观图标。隔离账本验证了转账、买入、卖出及丢失响应后的原节点核实，没有提交真实资金操作。已安装并打开 0.3.9，原有账户库、设备资料和节点设置的安装前后摘要一致。见 [验收记录](../installers/0.3.9/linux/validation.json)。

跨平台静态检查通过。尝试的 `aarch64-apple-darwin` Rust 检查仍受 Linux 主机缺少 Apple SDK/兼容 C 编译器限制，`ring` 无法接受 Apple 编译参数；本轮只发布并原生验证 Ubuntu 安装包。

0.3.10 补充：本地资产工作区顶部的 Bancor 与资产导航按钮增加常驻边框，选中时加强边框与背景。实际 Ubuntu 安装包通过 9 组原生资产验收，已检查深色未选中、深色选中及浅色选中截图；类型检查、产品身份自检/清单及双品牌 UI 检查通过。已安装并打开 0.3.10，账户库、设备资料与节点配置摘要保持一致。此版仅调整桌面导航 CSS 和发行版本，未重跑 0.3.9 的 Rust 单元测试、登录验收或跨平台检查。见 [0.3.10 验收记录](../installers/0.3.10/linux/validation.json)。
