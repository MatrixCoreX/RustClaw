# 桌面独立资产工作区（0.3.6）

## 用户使用

首页展示桌面已保存的本地账户、自定义名称、完整公钥、复制按钮和备份状态。每个账户都有“资产 / 转账”和“Bancor 交易”入口；无需连接或登录硬件设备。没有账户时，从“创建 / 恢复账户”进入原生安全窗口。

资产工作区提供余额、估值、AIC/USD 转账、交易流水、来源与方向筛选、分页和待确认结果查询。Bancor 保留行情、池边际价格 K 线、市场成交、标准/SWAP 布局、图表最大化、买入与卖出。账户选择器仍位于网页相同位置，名称紧跟“桌面本地账号”，保留完整公钥复制。独立工作区仅列出本地账户；连接设备后的控制台仍可切换硬件账户。

独立账户没有硬件设备奖励。Bancor 中的 APR 页明确说明需要从首页连接设备后查看设备奖励；不把本地余额当作硬件奖励，也不生成虚构 APR。

首次进入资产工作区使用 `config/asset-nodes.json` 提供的默认资产节点，之后记住用户选择。页面支持切换、添加节点，连接失败可重试。回到首页会断开资产连接并锁定密钥库。

## 实现与安全边界

- 所有修改位于 `desktop/`。共享 Assets/Bancor 页面由桌面构建适配器复用；未改网页 UI 或服务器代码。
- 独立工作区使用新的原生资产会话，不创建设备登录态、管理员身份或浏览器 Cookie。
- 资产连接直接调用节点 `/v1/nni/server/assets/owner/*` 的固定 owner 协议。随机的连接绑定值只用于挑战上下文，不是管理员凭据；每笔资金写入仍需要账户私钥签名。
- 外部节点必须使用系统信任的 HTTPS；关闭代理和重定向，不忽略证书错误、不降级 HTTP。HTTP 仅接受字面 IPv4/IPv6 回环地址。自签名节点需要有效的受信证书；独立模式不自动导入证书。
- 连接时同时验证 Assets/Bancor 能力及相同账本标识，并绑定节点 origin 和账本。每次读取及签名前继续校验；切换或断开节点会取消旧会话、撤销未确认请求并锁定密钥库。
- 行情读取仅允许固定市场、K 线、成交和流水路径，查询参数受限；没有开放通用 HTTP 代理或任意签名接口。
- 完整流水经原生 Explorer 投影：校验账户、方向、分类、分页、整数金额与格式化金额一致性，然后复用网页的筛选和分页组件。原设备网关 v1 流水能力不变。
- K 线固定使用 `pool_marginal_usd_per_aic`，与网页市场价格口径一致。
- 私钥与密码不会进入首页或交易表单。继续使用本机加密密钥库、系统凭据库、已验证备份要求、逐笔原生密码确认、挑战条款校验和结果持久化。不自动重发资金写入。
- 新节点列表保存在 `asset-wallet/nodes-v1.json`，采用现有安全文件读写；没有迁移或重写原账户密钥格式。
